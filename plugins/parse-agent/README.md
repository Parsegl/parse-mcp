# Parse

See how often ChatGPT Search and Google AI Mode mention your brand, which competitors they recommend, and which pages they cite. Ask “Which pages do AI answers cite when they recommend alternatives to my brand?” or “How has my brand’s share of mentions changed?”

The plugin includes the Parse research skill and connects Claude to the hosted Parse MCP server at https://agent.parse.gl/mcp. Tool calls send their arguments to Parse. These can include domains, search questions, filters, and workspace notes. Sign in with Parse for workspace features. Live checks and recurring tracking can use Parse credits.
